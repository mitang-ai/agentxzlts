# 网页导航的高度适配

- 常规桌面导航压缩到 52px/项，主功能与底部工具分区。设置、个人资料和工具始终固定在底部，不依赖滚动整条侧栏。
- 桌面视口低于 700px 时采用图标模式，保留 `aria-label` 与悬浮标题；极小高度只允许主功能区内部滚动，底部操作仍可点击。
- 手机继续使用横向底部导航，保留五个主要功能和个人资料入口；房间打开时沿用原有隐藏规则。

## 回归验证

隔离数据库和本地服务配置好后运行：

```sh
E2E_BASE_URL=http://localhost:3109 DATABASE_URL=<isolated-database> npx playwright test tests/e2e/rail-layout.spec.ts
```

该用例只允许 `localhost`，创建独立测试用户并在结束后清理。验证 1366×900、1366×768、1366×640、1024×768 无侧栏或主导航滚动，1366×300 底部设置与资料固定且主导航仍可操作，以及 390×844、320×568 手机导航全部可见、无横向溢出。
