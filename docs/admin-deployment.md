# 后台运行、升级与部署

## 本地使用与首位管理员

要求 Node.js ≥22，普通用户运行数据库。Linux/macOS 已验收；Windows 可使用 WSL，npm 包提供 Windows x64 数据库二进制但本次未在 Windows 实机验收。

首次安装在仓库根目录运行 `npm ci`，终端一 `npm run db:start`，终端二 `npm run dev`。访问 http://localhost:3000 注册自己的账号，然后在第三个终端、仓库根目录执行：

```bash
npm run admin:init -- your@email.com
```

命令只允许首次初始化，要求邮箱已注册且状态正常，授权及原因写入 Audit。已有管理员后，必须由超级管理员在 `/admin/security` 授予固定角色。没有默认管理员账号、默认管理员密码或自动把首位注册用户变成管理员的逻辑。

使用该账号访问 http://localhost:3000/admin。后台登录使用同一安全 Session；普通房间主持人没有网站管理员权限。

## 升级现有聊天系统

停止 Web 服务，先备份数据库及 `.data/files`。拉取本分支并 `npm ci`。启动开发数据库时会自动执行追加迁移；独立生产数据库需显式执行：

```bash
DATABASE_URL='postgresql://...' npm run db:migrate
npm run build
npm start
```

不修改旧迁移、不重新初始化已有数据库、不清空原房间。迁移保留原实体关系，并追加管理状态、管理表、会话元数据、持久化控制事件与遥测。重复执行迁移会核对 journal 校验值，已应用迁移不会重跑。新 Web 版本必须在迁移完成后启动。

## 生产配置

- 使用 HTTPS 与匹配的 `APP_ORIGIN`，独立数据库凭据和持久化私有存储；不要使用仓库的本地开发密码上线。
- `STORAGE_DIR` 建议绝对路径，数据库备份和对象文件备份必须一起验证恢复。
- `TRUST_PROXY=true` 只能在受信反向代理覆盖 `X-Forwarded-For` 且无法绕过代理直连时启用。关闭时不把用户伪造的头当 IP，后台明确显示规则尚未启用；来源记录显示未知而不编造 IP 或地理位置。
- `BACKUP_STATUS_URL` 可链接基础设施备份控制台。没有配置时显示未接入，不伪造“备份成功”。生产管理员推荐由受信身份网关实施 2FA，本应用不声称已实现 TOTP/短信认证。
- 下载字节、请求、P95、HTTP 错误、登录结果和 SSE 创建/关闭记录是本应用真实测量；不会等同于云平台账单。月度成本和平台带宽以基础设施计费为准。
- 可选 Supabase Storage Adapter 延续原系统边界，仍需目标 Supabase 服务实测。主验收链路是 PostgreSQL + HttpOnly Session + SSE + 私有文件。

## 运营设置与统计

Logo/Favicon 上传支持 PNG/JPG/WebP/ICO，限制 2MB 并校验类型；不接受可执行的任意 SVG 或 HTML。网站名称、首页简介、SEO、备案、页脚、联系方式由统一配置提供。

统计工具只接受百度 ID、GA4 ID、Umami 服务地址和网站 ID，不提供任意脚本输入。只在对应开关开启时加载；后台管理页面不加载统计脚本。在线页面的统计配置变化会刷新页面，确保关闭后不继续运行旧脚本。

任务、上传、建房开关支持全量、指定用户、指定房间、管理员测试、确定性百分比灰度。前台读取能力，服务端和数据库事务再次检查；默认任务/上传/建房开启，Agent 与联机席位关闭，未上线的能力不能通过开关冒充开启。

全局配置和 Session 由持久化控制游标每 3 秒同步。房间变化使用已有 SSE/NOTIFY，并每 5 秒核对数据库 Event Cursor。断线恢复先读取当前状态和事件，客户端不会因漏掉一次通知继续保有旧权限。

## 高风险操作与维护

封禁、限制、强制下线、冻结/软删除、转移主持人、移出成员、删除消息、隔离/删除文件、修改角色、IP 规则、设置及清理均要求确认对象与明确原因，服务端再次验证。最后一位超级管理员不能被降级、移除或封禁；非超级管理员不能限制、编辑或撤销管理员账号会话。

房间与文件管理删除是软删除，保留恢复能力；普通房主的原“解散房间”仍为原有业务行为。软删除文件保留存储实体，不假装已释放物理空间。

清理过期数据删除过期 Session、失效邀请、超过 30 天请求遥测、超过 90 天登录记录、陈旧连接；审计不会被该操作删除。孤立文件只清理 **超过 24 小时且无 File 引用** 的对象，以免误删上传中的对象。数据库记录待清理路径，存储失败时保留重试队列，可再次执行同一清理操作；活动文件和软删除但可恢复的文件不被当作孤立对象。

CSV 导出最多 1000 条当前筛选结果，防止大表一次加载；超大数据按日期分段导出。导出带 Audit，并防护 CSV 公式注入。运营趋势也可导出，不开发复杂 BI 或 Excel 引擎。

## 验证

数据库和生产构建启动后运行 `npm test`、`npm run test:e2e`。后台端到端验收使用临时真实账号和对象，并在结束时还原设置、清理自己的夹具；截图保存在 `docs/admin-screenshots`，截图里的数字来自测试期间实际数据库。
