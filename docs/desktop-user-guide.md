# Windows 桌面版操作说明维护约定

用户阅读的完整操作指南位于 `/guide`，不要求登录；网站左下、登录页和“我的 Agent”提供入口。

- `/guide/llm`：直接返回 `text/markdown; charset=utf-8`，不嵌入 HTML，也不包含配对凭据。
- “复制完整文档”：复制所有章节与当前有效发布信息。
- “复制 LLM 阅读指令”：一句话导航到 Markdown；不作为额外执行授权。
- `/api/desktop/release`：读取固定本地 `apps/web/public/desktop/release.json`，只返回经过校验的公开元数据；缺失或无效返回 `404 DESKTOP_NOT_PUBLISHED`，不能显示假下载。

人类页面与 Markdown 的正文共享 `apps/web/src/lib/operation-guide.ts`。更新产品行为时，应修改此数据源，而不是分别维护两份互相矛盾的说明。

## 协作岛小管家

桌面版启动时直接显示正式协作岛网页，网页上方不叠加导航、下方不叠加本机管理工具栏。通过系统托盘打开独立的“协作岛小管家”窗口；单独关闭设置窗口不会影响正式网页。

小管家只负责轻量查看和设置：

- 显示真实共享 Hub 状态和本客户端登记的 Agent 状态；Agent 列表只读，不提供配对表单、命令参数、工作目录、执行器切换或 MCP 配置编辑。
- “刷新状态”只重新读取本机状态，不重新配对，不启动或停止 Agent，不向协作岛服务器发起版本查询。
- “关闭协作岛时也退出小管家”默认关闭：关闭正式协作岛窗口时隐藏到托盘，共享 Hub 继续运行。开启后，关闭正式窗口或托盘退出会停止 GUI 与共享 Hub，导致本机 Agent 的协作岛连接中断。托盘退出也遵循此设置。
- “开机启动协作岛小管家”控制 Windows 登录后的后台启动，不默认弹出协作岛窗口；默认关闭。
- “检查新版本”直接查询项目官方 GitHub Releases，允许复用近期查询结果，不增设网站轮询服务。查询失败明确显示无法确认，旧缓存仅供参考，不能伪报“最新”。发现新版后由用户点击前往官方发布页，不自动下载安装或降级。
- “操作指南”在正式网页打开共享指南；初次安装组件的进度仅在准备阶段显示，完成后收起。

连接 Agent 的入口仍在协作岛“我的 Agent”：用户复制连接指令，交给对应 Agent 执行。小管家不另造第二套身份或配对流程，也不因查看状态自动启动 Hub。

## 安装发布

清单 schema 为 `1`，平台固定 `win32`、架构 `x64`。EXE 只接受当前版本对应的 `Island-Setup-{version}-x64.exe`，来自同站 `/desktop/` 或项目官方 GitHub Releases；不代理用户提供的网址。

推荐下载 `/desktop/install.ps1`，或者复制先校验脚本摘要再运行的 PowerShell 命令。清单中的 `installScriptSha256` 必须由最终发布脚本字节计算；未提供该摘要时不显示引导执行入口。EXE 的 `sha256` 和 `size` 也必须来自实际构建产物。

未签名版本必须显示 Windows 安全提示说明；不能承诺绕过 SmartScreen。安装、配对、房间批准、执行器就绪和业务任务完成是不同阶段，不能把下载或安装成功当成任务完成。

## 非破坏刷新约定

网页自己的左下刷新按钮派发可取消事件 `island-desktop-refresh`。Island 与 MyAgents 接收后调用 `preventDefault()` 并更新服务端数据，不重新装载页面或重建编辑组件。桌面版不再另放一条刷新工具栏。

刷新不清除聊天草稿、回复对象、头像/昵称编辑、未保存选项、邀请状态，不调用新配对、停止后台或撤销设备。普通刷新数据请求失败应显示对应错误，不能报告重连成功。网站左下同名按钮复用同一事件。

小管家“刷新状态”只查询本机状态，不重新加载网页，也不能丢弃页面编辑内容。

## 边界

首发 Windows 10 22H2 x64 / Windows 11 x64。GUI 与提示词入口复用同一 Hub，但身份配置和工作区分别隔离。普通 MCP 不保证自动唤醒；独立工作区不是系统级沙箱；旧客户端不自动删除。是否随协作岛窗口关闭而停止 Hub 由小管家偏好控制，默认保留后台连接；账号退出和 Agent 撤销不能混同。
