## 关键行为证据

- 邀请 Markdown 可重复读取但不消费配对码；配对/撤销/删除/过期后失效。下载客户端核对固定 SHA-256。
- 用户级 Agent 注册后分别加入房间、等待批准；切换使旧交付失效，讨论邀请不能自行声明获得开发权限。旧凭据没有自动扩权。
- 各传输的自由输出先进入本人私有审核；他人确认返回拒绝，确认前房间没有对应消息，编辑确认后只产生一条消息，重复确认不重复发布。
- 已知路径/密钥/私网信息在统一出口被拦截；本人确认也不能强行公开。客户端与 ACP 子进程测试验证默认不继承桥接器的模型/云凭据环境变量。
- 文件字节上传前要求本人批准指定摘要；未经许可、摘要改变、授权/任务变化的交付被拒绝。双 Node 的实际 Git 开发、文件回传、审核合并没有绕开本人授权。
- 头像实际上传、裁剪、保存；检查非法格式、过大输入、其他用户资源引用和非共同房间访问。服务端重新编码，不保存原图元数据。
- 其他成员可看同一份协作状态但不能编辑主持设置。后台可见尚未加入房间的设备，修改安全策略记录原因及前后值，重复撤销保留明确反馈。
- 自研 Agent 预览的 Key、探测、执行均不可用；模型多选只是示意交互，没有模型网络请求或任务执行。

## 复测入口

在独立检出目录中安装锁文件依赖，先按照 README 的手工开发流程启动**专用测试数据库**、应用迁移及本地网站。必须核对 `DATABASE_URL`、`STORAGE_DIR` 和保存的安装配置，不得指向线上。

```bash
npm ci
# 配置专用数据库后：
npm run db:migrate
npm run typecheck
npm test
npm run build

# 在另一终端启动已构建网站：
npm start

# 本地网站和专用数据库就绪后：
E2E_BASE_URL=http://localhost:3104 E2E_STORAGE_DIR=/path/to/test-files npm run test:e2e

# 仅复测本次最后涉及的流程：
E2E_BASE_URL=http://localhost:3104 E2E_STORAGE_DIR=/path/to/test-files npm run test:e2e -- \
  tests/e2e/agents.spec.ts \
  tests/e2e/chat-presence-invitations.spec.ts \
  tests/e2e/privacy-agent-center.spec.ts
```

上面的端口是示例，需要同时设置应用 `PORT=3104`、`APP_ORIGIN=http://localhost:3104`。所有终端使用相同的测试 `DATABASE_URL` / `STORAGE_DIR`。如浏览器未安装，可设置 `CHROMIUM_PATH` 指向已安装 Chromium。Windows PowerShell 使用 `npm.cmd` 及 `$env:` 设置环境变量，不直接粘贴 Bash 环境前缀。
